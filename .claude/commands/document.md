# Review a procedure-documentation batch

Use /document or /document COUNT only for a requested research batch. Read the
[module-aware workflow](../../docs/claude_instructions.md),
[naming contract](../../docs/naming.md), [provenance](../../docs/provenance.md)
and [contribution rules](../../CONTRIBUTING.md) first. Those documents own
evidence, private inputs, validation and commit policy; this command adds no
alternative rules and does not authorize an emulator run or source mutation.

Read the existing ignored workflow/batch_procedures.txt. If absent, report that
make prepare-batch COUNT=40 is required; do not manufacture observations. Locate
each exact definition in the current module tree and analyse instructions,
callers, consumers, tables and profile branches. Perturbation images, scene
names and changed RAM bytes are leads, not established semantic identities.

Prepare workflow/rename_batch.csv with old_name,new_name,description, unique
valid labels and record-specific evidence. Leave uncertain roles neutral and
report unresolved cases. Applying make rename, recording exact-address evidence
and rebuilding both profiles follow the workflow only when authorized.

Summarize the proposal, evidence limits and exact validation performed. Use make
verify-all for current regional identity, not obsolete single-source filenames
or a report's processed flag. Never stage a ROM, private trace, generated
report, unrelated changes or a broad source backup.
